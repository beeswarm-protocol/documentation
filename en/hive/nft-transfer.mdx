# Main NFT Transfer

The Queen can transfer her main NFT to another wallet. When this happens, the receiving wallet gains all rights to the Hive — including bonuses and the links to all registered bees. The original wallet loses these rights, retaining only its earnings history.

<Warning>
This action is irreversible. Transfer the main NFT only if you are completely certain.
</Warning>
