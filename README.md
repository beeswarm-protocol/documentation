# BeeSwarm App

A decentralized financial ecosystem that makes crypto simple, secure, and accessible to everyone — built on **BNB Smart Chain (BSC)**.

## Technology Stack

- **Blockchain**: BNB Smart Chain + EVM-compatible chains
- **Smart Contracts**: Solidity ^0.8.x
- **Frontend**: React + Vite + ethers v5 + viem
- **Development**: Foundry + OpenZeppelin libraries

## Supported Networks

- **BNB Smart Chain Mainnet** (Chain ID: 56)

## Features

- Non-custodial wallet running directly in the browser — no installs or complex setup required
- DEX aggregator routing through PancakeSwap V2/V3 with transparent fees and price impact warnings
- Encrypted P2P messaging between wallet addresses with no central servers or intermediaries
- Onchain cashback mechanism enabling BNB and crypto payments for everyday commerce
- Multi-account management made easy
- WalletConnect support for connecting to any dApp via QR code or link
- Full offline support as an standalone app with locally encrypted storage
- Internationalized in Portuguese, Spanish, and English
